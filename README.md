# 书伴 · AI 伴读 Agent Demo

以公版《朝花夕拾》（鲁迅）为例的阅读器 AI 伴读助手。核心原则：**回答只依据原文，每条引用都由代码逐字核验**。

**演示视频**：[书伴_演示视频.mp4](书伴_演示视频.mp4)（约 2 分钟，带字幕）

## 运行

需要 Node 18 以上，无第三方依赖。

1. 复制 `.env.example` 为 `.env`，填入 `DEEPSEEK_API_KEY=`（`.env` 已在 `.gitignore` 中）
2. 启动：`npm start`，打开 http://127.0.0.1:8790
3. 评测看板：http://127.0.0.1:8790/eval
4. 重新跑评测：`npm run eval`（约 1–2 分钟，结果写入 `eval/results.json`）

## Agent 架构

```
用户输入（提问 / 划线）
  → 意图路由（规则层 + LLM）：书内问答 / 划线解释 / 章节摘要 / 读后出题 / 书外请求，同时定位篇目和关键词
  → 取上下文：章节全文 + 全书检索补充（字二元组 + IDF）
  → 技能生成（版本化提示词，JSON 输出）
  → 拒答前复查：判断"书中没有"时，换检索得分第二的篇目再查一次
  → 引用核验（代码）：摘录逐字比对原文；段落标错自动纠正，对不上就移除；检测大段照抄
```

| 意图 | 处理 | 护栏 |
| --- | --- | --- |
| 书内问答 | 章节全文 + 检索，Prompt v3 | 逐字引用、找不到依据就拒答、错误前提先指出 |
| 划线解释 | 定位划线段落 ± 1 段 | 书外知识单独放进「书外补充」 |
| 章节摘要 | 整篇原文 | 每个要点带引用 |
| 读后出题 | 整篇原文 | 每题答案依据经过核验 |
| 书外请求 | 固定话术 | 不调用生成模型 |

## 评测

`eval/cases.json`，36 题：

- 事实问答 14、书中没有 5、错误前提 5（这 24 题对比 4 个版本）
- 划线解释 5、章节摘要 3、读后出题 2、书外请求 2（检查路由、篇目和引用）

| 版本 | 改动 |
| --- | --- |
| 裸模型 | 不给原文，直接问 |
| Prompt v1 | 检索原文后回答 |
| 书伴 v2 | + 逐字引用、拒答、前提校验、代码核验 |
| 书伴 v3 | + 章节全文上下文、拒答前换篇目复查 |

评分：正确率、拒答、前提识别和幻觉由 LLM-as-Judge 判定（与被测模型相同，需人工抽检）；引用核验率和依据命中率由代码计算。

## 文件

- `lib/agent.js`：路由、检索、技能、核验
- `lib/llm.js`：DeepSeek 调用（密钥只从 `.env` 读取）
- `data/book.json`：原文（来自维基文库，公有领域）
- `public/`：阅读页和评测看板
- `eval/`：评测集、运行脚本和结果
